# Explore the Filesystem

Navigate to each of these locations, in this order, and record the
absolute path you land on after each `cd` to `/workspace/transcript.txt`
(one path per line, in the order you visited it):

1. `/etc`
2. `/var/log`
3. `/opt`
4. your home directory

Finish back in `/workspace`.

Get a shell: `docker exec -it breaklab-lnx-003 bash`
