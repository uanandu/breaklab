# Identify the Machine

You have been given shell access to an unfamiliar Linux host. Before changing
anything, collect its basic operating context — the same seven commands from
the guided walkthrough above, run once more on your own.

Record these values in `/workspace/answers.env`, one `KEY=value` per line:

```
DISTRIBUTION=
KERNEL=
HOSTNAME=
USER=
SHELL=
WORKING_DIRECTORY=
ARCHITECTURE=
```

Collect every value from the running environment itself — don't hard-code
anything from the lesson.

Get a shell: `docker exec -it breaklab-lnx-001 bash`
